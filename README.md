# 🧪 QA Automation Project

## 📌 Descrição do Projeto

Este projeto de automação de testes foi desenvolvido com o objetivo de aprimorar conhecimentos em testes automatizados utilizando Cypress, simulando cenários reais de validação de aplicações web.

O foco está na criação de testes E2E, validações funcionais e organização do código de forma clara e escalável.

---

## 🎯 Objetivos

- Praticar automação de testes E2E
- Validar fluxos funcionais de formulários
- Trabalhar com cenários positivos e negativos
- Melhorar a organização e legibilidade dos testes
- Simular boas práticas utilizadas em projetos reais de QA

---

## 🧰 Tecnologias Utilizadas

- Cypress
- JavaScript (ES6+)
- Node.js
- VS Code

---

## 📈 Boas Práticas Adotadas

- Separação de responsabilidades (testes, páginas e dados)
- Reutilização de código
- Organização dos testes por funcionalidade
- Uso de massa de dados para diferentes cenários
- Escrita de testes claros e de fácil entendimento
- Estrutura preparada para evolução e escalabilidade
